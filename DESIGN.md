# DESIGN.md - LogbookFlex Design System

> Visual direction: Notion Design System for academic, clinical, and internship logbooks.
> Dials: ENERGY 1 / RHYTHM 2 / MOTION 1

## 1. Identity & Purpose
- **Product**: LogbookFlex (Sistem Catatan Harian & Presensi Magang, KKN, PKL, Skripsi)
- **Target Audience**: Mahasiswa, dosen pembimbing lapangan, pembimbing klinik, instruktur industri.
- **Mood**: Terstruktur, tenang, terpercaya, nyaman dibaca untuk dokumentasi akademik dan klinis.

## 2. Color System (Notion Workspace Palette)
- **Canvas & Surface**:
  - Light: Canvas `#ffffff`, Surface `#f7f6f3`, Soft `#fafaf9`
  - Dark: Canvas `#191919`, Surface `#202020`, Soft `#262626`
- **Hairline Borders**:
  - Light: `#e5e3df` (soft), `#c8c4be` (strong)
  - Dark: `#2e2e2e` (soft), `#383838` (strong)
- **Primary Accent**: Signature Notion Purple (`#5645d4`, hover `#4534b3`)
- **Pastel Property Badges (Multi-select Properties)**:
  - Mint (`#d9f3e1` / `#1aae39`): Klinis, disetujui, capaian inti
  - Lavender (`#e6e0f5` / `#5645d4`): Bimbingan, evaluasi, teori
  - Sky (`#dcecfa` / `#0075de`): Mandiri, riset, praktik
  - Peach (`#ffe8d4` / `#d95b00`): Diajukan, sosialisasi, review
  - Yellow (`#fef7d6` / `#8c6b00`): Laporan, administrasi
  - Gray (`#f0eeec` / `#5d5b54`): Draft, metadata

## 3. Typography
- Font Family: Inter / system sans-serif with clean tracking.
- Hierarchy:
  - Page Title: 24-28px font-bold tracking-tight
  - Section Headings: 14-16px font-semibold with emoji icon
  - Body: 13-14px font-normal leading-relaxed
  - Metadata / Tags: 10-11px font-medium or semibold

## 4. Antislop Quality Locks
- No em dashes (`—`) in UI copy: use comma, colon, or parentheses.
- No fake numbers or fake testimonials: all statistics reflect actual user data.
- Every button has a functional action or clear state.
- Both Light & Dark modes fully supported and readable.
- Mobile layout responsive without overflow (tap targets min 44px).
